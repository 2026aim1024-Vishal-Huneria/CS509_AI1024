## 9.1 MST Results Table

### Minimum Spanning Tree (MST)

Two MST algorithms were implemented and compared:

- **Kruskal's Algorithm**
- **Prim's Algorithm**

Both algorithms were tested on weighted undirected graphs of different sizes. The total MST weight produced by both algorithms was compared to verify correctness, and their execution times were measured for performance comparison.

### Correctness

For each test case, the total MST weight generated by Kruskal's algorithm was compared with the total MST weight generated by Prim's algorithm.

If:

`Kruskal Weight = Prim Weight`

then both algorithms produce the same minimum spanning tree cost, and the test case is marked as **Pass**.

All test cases produced identical MST weights using both algorithms. Therefore, all test cases passed the correctness check.

### Complexity

**Kruskal's Algorithm**

- Time Complexity: **O(E log E)**
- Space Complexity: **O(V + E)**

Kruskal's algorithm sorts all edges by weight and uses a Disjoint Set Union (DSU) structure to avoid cycles while constructing the MST.

**Prim's Algorithm**

- Time Complexity: **O(E log V)** using a binary heap / priority queue
- Space Complexity: **O(V + E)**

Prim's algorithm starts from a vertex and repeatedly selects the minimum-weight edge that connects a vertex inside the MST to a vertex outside the MST.

### Result Analysis

The results show that both Kruskal's and Prim's algorithms produce the same MST weight for every test case.

For the smaller graphs, Prim's algorithm has lower execution time:

- For `mst_10.txt`, Prim takes **0.002 ms** compared to Kruskal's **0.005 ms**.
- For `mst_100.txt`, Prim takes **0.026 ms** compared to Kruskal's **0.068 ms**.

For the larger graphs, Kruskal's algorithm performs better in the measured tests:

- For `mst_10000.txt`, Kruskal takes **2.916 ms** compared to Prim's **5.410 ms**.
- For `mst_50000.txt`, Kruskal takes **20.786 ms** compared to Prim's **27.698 ms**.
- For `mst_100000.txt`, Kruskal takes **46.976 ms** compared to Prim's **68.760 ms**.

The execution times depend on the graph representation, implementation, hardware, and input graph structure. Therefore, the measured times represent the performance of the implemented programs on the tested system.

### Observation

Kruskal's and Prim's algorithms produce the same minimum spanning tree weight for all tested connected weighted undirected graphs.

The actual edges selected by the two algorithms may differ when a graph contains multiple possible MSTs with the same minimum total weight. However, the total MST weight should remain the same.

The experimental results confirm the correctness of both implementations. The execution-time comparison also shows how the performance of the two algorithms changes as the number of vertices and edges increases.
