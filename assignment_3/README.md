## 9.1 MST Results Table

### Minimum Spanning Tree (MST)

Two MST algorithms were implemented and compared:

- **Kruskal's Algorithm**
- **Prim's Algorithm**

Both algorithms were tested on weighted undirected graphs. The total MST weight produced by both algorithms was compared to verify correctness.

### Correctness

For each test case, the total weight of the MST generated by Kruskal's algorithm was compared with the total weight generated by Prim's algorithm.

If:

`Kruskal Weight = Prim Weight`

then both algorithms produce the same MST cost and the test case is marked as **Pass**.

### Complexity

**Kruskal's Algorithm**

- Time Complexity: **O(E log E)**
- Space Complexity: **O(V + E)**

**Prim's Algorithm**

- Time Complexity: **O(E log V)** using a binary heap
- Space Complexity: **O(V + E)**

### Observation

Kruskal's and Prim's algorithms should produce the same minimum spanning tree weight for a connected weighted undirected graph, although the actual edges selected may differ when multiple MSTs exist with the same total weight.

The execution time of both algorithms can be compared across different graph sizes to observe their performance as the number of vertices and edges increases.
